🎧 AmphionASR GLCLAP-Hotword 热词召回 Demo

上传音频 + 输入候选热词 → 模型按 帧级对齐 打分排序，并给出热词出现的时间位置（可点击播放该片段）。
打分口径与训练/评估完全一致：score = maxt ⟨gaudio(at), gtext(h)⟩， 按 cos 排序；窗口分 seg 只用于定位与播放，不参与排序。

① 输入

点击选择 或 拖拽音频到此处
—

② 参数

打分温度固定为训练值（GLCLAP-Hotword 学习到 ≈0.0148，即 softmax 尺度 ≈67.4），与训练/验证一致； 此处不提供温度调节，避免与评估口径不一致。
⚠️ 会议音频中位时长约 67 秒（最长 842 秒）。截断值必须覆盖热词所在位置，否则热词会被丢掉。

③ 召回结果

音频电平 相似度曲线（当前选中热词） 匹配片段 播放头 在波形/曲线上点击 = 从该位置播放并选中该热词
